⑥ Android App 版

想在手机上直接操作（不需要电脑、不需要数据线）：装下面的 APK。App 支持 root / Shizuku 两种提权方式， 在本机直接改调试开关、开 tcpip 端口、写 adb 授权公钥。
⬇ 下载 ADBTool.apk（44 KB）

怎么用

  1. 手机用数据线连电脑，设置里打开「开发者选项」和「USB 调试」。
  2. 点上面「选择 USB 设备并连接」，在弹窗里选中你的手机。
  3. 手机弹出「允许 USB 调试吗」→ 勾「一律允许」→ 允许。连不上就拔插一次数据线重来。
  4. 点「一键全自动」，它会依次：开开发者选项 → 开 USB 调试 → 开 Wi-Fi → 读 IP → 开 5555 端口 → 读无线调试端口。
  5. 拿到 adb connect IP:5555 后，拔掉数据线，手机就在无线调试状态了。
Android 11+ 的「无线调试」是 TLS + 配对码模式，网页端只能读出端口号，配对需要系统弹窗交互。 想要完全免配对，用 App 版在 root 环境下直接开传统 5555 端口。
